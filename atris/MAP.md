## Critical Files

- `prisma/schema.prisma:75`  
Owns the data model. The app is now single-user and no longer has `User` or Better Auth tables; learning state remains app-global through `Attempt`, `StudySession`, `TopicMastery`, `ReviewQueue`, and `ChatMessage`.

- `src/app/api/attempts/route.ts:22`  
Most important runtime mutation path. Records attempts, updates mastery/review scheduling, and computes the next recommendation.

- `src/lib/task-selector.ts:257`  
Encodes the product's central differentiation: prerequisite-gated, review-aware task selection instead of naive random practice.

- `src/lib/learning-signals.ts:34`  
Computes Math Academy-style recent-struggle and automaticity signals that feed targeted remediation and fluency work.

- `src/lib/learning-state.ts:18`  
Centralizes topic/mastery/review/signal loading so recommendation logic is consistent across `study-next`, session creation, and post-attempt follow-ups.

- `src/app/(app)/sessions/[id]/page.tsx:67`  
Largest frontend flow. Good place to inspect timing, resume behavior, result summaries, and AI-context integration.

- `scripts/import-gmatclub.ts:165`  
Important data-quality caveat: imported questions currently use placeholder `"A"` as the correct answer when the source does not expose it.
